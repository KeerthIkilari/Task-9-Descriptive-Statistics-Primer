Project Overview

This project focuses on understanding and analyzing descriptive statistics using Python, Pandas, NumPy and the Iris dataset.

Objective

To calculate and interpret the following statistical measures:

- Mean
- Median
- Mode
- Standard Deviation
- Percentiles
- Skewness
- Data Range

Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Dataset

Iris Dataset

The Iris dataset contains 150 records and 4 numerical features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Project Implementation

1. Imported the required Python libraries.
2. Loaded the Iris dataset.
3. Calculated mean, median and mode.
4. Calculated standard deviation and percentiles.
5. Created a summary statistics table.
6. Generated histograms and box plots.
7. Analyzed skewness and data spread.
8. Prepared interpretation and conclusion.

Visualizations

- Histograms to understand data distribution.
- Box plots to understand data spread and identify possible outliers.

Conclusion

Descriptive statistics helps summarize and understand numerical data. This project demonstrates how statistical measures can be calculated and interpreted using Python.
